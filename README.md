# ECON1626 AI Future Forecast

**Repository name required by the assessment:** `econ1626-ai-future-forecast`  
**Main webpage:** `forecast.html`  
**Topic:** Australia's AI Productivity Bargain: how AI may reshape the Australian economy by 2030.

## Project overview

This project is an AI 2027-inspired interactive web essay for ECON1626 Assessment 3. It argues that AI is likely to become a productivity amplifier for Australia by 2030, but the size and distribution of gains depend on adoption speed, worker skills, governance and trust.

The essay includes:

- a clear thesis and near-term forecast horizon;
- AI capabilities mapped to economic channels such as productivity, tasks, wages and market structure;
- baseline, upside and downside scenarios;
- an interactive policy simulator;
- data-driven visuals using embedded JavaScript;
- methods, assumptions, limitations and AI-tooling disclosure;
- RMIT Harvard-style references.

## Files

- `forecast.html` — the complete interactive web essay. Open this file in a browser or publish it through GitHub Pages.

## How to preview locally

Open `forecast.html` directly in a web browser. No build tools or external JavaScript libraries are required.

## How to publish on GitHub Pages

1. Create a GitHub repository named `econ1626-ai-future-forecast`.
2. Push this folder to the repository.
3. In GitHub, go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and the root folder `/`.
6. Open the GitHub Pages URL and confirm that `forecast.html` renders correctly.
7. Submit the public GitHub Pages URL or the repository/file upload according to Canvas instructions.
